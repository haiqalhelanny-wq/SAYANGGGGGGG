# Happy 19th Birthday Sayang ❤️

## How to use
1. Open `index.html` in Chrome, Edge, or another modern browser.
2. Click **+ Add Our Photos** and select your pictures. You can select multiple photos.
3. Click **+ Add Music** and select the audio file you want to play.
4. For Bruno Mars' **Risk It All**, use an audio file you legally obtained/are permitted to use; the website does not include copyrighted music.
5. To permanently change the written message, edit the text inside the `My Wish For You` section in `index.html`.

## Easy editing
- Change colors/design: `style.css`
- Change text, birthday sections, or add more sections: `index.html`
- Change photo/music behavior: `script.js`

The photo and music upload controls work locally in the browser. They are not uploaded to a server.
